## Open-Source Developer Starters & Tools (GitHub)

- **[compose-pcm-sfx](https://github.com/simple-free-apps/compose-pcm-sfx)** *(MIT)* — Pure-Kotlin procedural 16-bit PCM `AudioTrack` SFX synthesizer library & Jetpack Compose demo app (zero external `.ogg`/`.mp3`/`.wav` assets).
- **[godot4-android-3d-starter](https://github.com/simple-free-apps/godot4-android-3d-starter)** *(MIT)* — Godot 4.7 mobile 3D touch-orbit camera, procedural PBR stage & bilingual EN/AR RTL starter with ARM64 debug APK.
- **[android-compose-puzzle-starter](https://github.com/simple-free-apps/android-compose-puzzle-starter)** — 5-level Jetpack Compose & Canvas conduit puzzle starter with BFS solver, dual `noAds`/`withAds` flavors, and procedural `AudioTrack` SFX.
- **[offline-speech-to-text-android-guide](https://github.com/simple-free-apps/offline-speech-to-text-android-guide)** *(MIT / CC BY 4.0)* — On-device Android ASR guide, `whisper.cpp` GGML model size reference, and `benchmark_rtf.py` CLI.
